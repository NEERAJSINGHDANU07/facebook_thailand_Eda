## 📌 Project Overview

This project focuses on performing **Exploratory Data Analysis (EDA)** on the **Facebook Thailand dataset** to understand data patterns, trends, distributions, relationships, and user engagement through data analysis and visualization.

The main goal is to **clean, explore, visualize, and analyze the dataset** to extract meaningful insights using Python and popular Data Science libraries.

---

## 🎯 Objectives

Through this project, we aim to:

* Understand the structure and characteristics of the dataset
* Perform data cleaning and preprocessing
* Identify missing and duplicate values
* Analyze numerical and categorical variables
* Understand data distributions
* Find relationships between important variables
* Identify patterns and trends
* Generate meaningful insights from the dataset
