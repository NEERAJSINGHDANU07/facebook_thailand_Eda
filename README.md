# 📊 Facebook Thailand — Exploratory Data Analysis

This project focuses on performing **Exploratory Data Analysis (EDA)** on Facebook Thailand data to understand patterns, trends, and user engagement through data analysis and visualization.

## 📌 Project Overview

The objective of this project is to explore the dataset, clean the data, identify important patterns, and generate meaningful insights using Python.

## 🔍 Analysis Performed

- Data Loading
- Data Cleaning
- Missing Value Analysis
- Duplicate Value Analysis
- Data Type Analysis
- Descriptive Statistics
- Univariate Analysis
- Bivariate Analysis
- Correlation Analysis
- Data Visualization
- Pattern and Trend Analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 EDA Workflow

```text
Dataset
   ↓

   ↓
Data Understanding
   ↓
Data Cleaning
   ↓
Exploratory Data Analysis
   ↓
Data Visualization
   ↓

   ↓
Insights
```
